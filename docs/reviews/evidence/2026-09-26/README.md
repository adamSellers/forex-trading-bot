## Reproduce locally

Python 3.9+ (stdlib only), from the repository root:

```sh
python3 docs/reviews/evidence/2026-09-26/analyze_performance.py
python3 docs/reviews/evidence/2026-09-26/analyze_entries.py
python3 docs/reviews/evidence/2026-09-26/candidate_analysis.py
```

The scripts use adjacent retained inputs and regenerate their corresponding results. Checks cover exact broker prices/P&L/units/timestamps, opening completeness, balance reconciliation, interval/capacity consistency, sampled-excursion lifetime/count/extrema, quote-side R, broker-confirmed breakeven, rounded target levels, prior-four-bar touch evidence, and updated anchors after omitted observed entries. Candidate analysis stops on unresolved within-bar, capacity or anchor ordering that would alter an outcome. It deliberately does not invent replacement fills or a timed-exit price if the retained path cannot resolve one.

Run the isolated serializer observation with Node 20–22:

```sh
node docs/reviews/evidence/2026-09-26/price-bound-reproduction.cjs
```

Verified on **Node 22.23.1** against the reviewed v3.3 source. It invokes the actual `OandaClient.placeMarketOrder` with `_request` and logging stubbed, using a retained numerical fixture. It clears broker credential environment variables and does not load a database or dotenv. Zero network requests. It **asserts the former precision defect**, so it fails after the v4 correction; it is historical evidence, not a regression test that proves a correction. Production parameter checks and engine source tracing separately establish the source of the mismatch; this reproducer exercises broker serialization, not full engine orchestration.

## Files and boundaries

- `production-evidence.json`: reduced, account-free source records: 35 trades with initial risk, entry context and excursion samples; 36 intents; 166 decisions; 1,668 distinct completed-candle regime observations. It excludes full scan exports, operational settings, notifications and credentials.
- `broker-evidence.json`: reduced OANDA trade/transaction records for this interval plus M1 bid/ask candles through each original deadline and M15 midpoint candles. Retained balances/costs are AUD. No broker account identifiers or credentials.
- `trade-ledger.csv`, `ledger.json`, `performance-summary.json`, `broker-verification.json`: outputs of `analyze_performance.py`.
- `entry-analysis.json`: descriptive current/prior cohort groups and per-trade sampled-excursion checks from `analyze_entries.py`. MFE/MAE are sampled lifetime bounds, not tick-complete extrema.
- `candidate-results.json`: four conditional observed-fill comparisons, individual target paths, re-entry touch bars and full retained post-exit quote paths. Alternative exits use rounded level fills; slippage, changed risk state, dynamic sizing/conversion and replacement entries are unmodelled. Removed historical losses must not be presented as expected future profit.
- `execution-analysis.json`: independent audit of the complete temporary operational capture, including retry decisions, risk bounds, broker protection, cooldowns, scan gaps and dated logs. Some raw scan/log details are not retained here; this audit is not fully regenerated by the reduced-input scripts.
- `price-bound-reproduction.cjs` / `.json`: isolated serializer reproduction and its result.
- `manifest.json`: raw capture identity, times and SHA-256 values. Hashes identify files; they are not independent provenance. Raw captures remain in the local temporary directory and may not survive cleanup.
- `prepare_inputs.py`: optionally regenerate reduced inputs from the original local capture directory. It makes no service calls. Regeneration intentionally preserves measurements and limited numeric strategy settings, not operational exports.

No runtime code, trading defaults, production processes, orders, Git commits/publication or deployment were changed. No frontend build or full backend regression was run for this report and analysis-only change.
